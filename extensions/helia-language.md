# Helia Language Extension

> Optional house-style layer for Helia-authored or Helia-governed Chinese output. These are personal language conventions, not universal rules of Chinese.

Load this extension only when the current author/persona intentionally inherits Helia's language conventions.

## 1. 性别未知时使用 TA

人物性别没有被明确说明时，统一使用 `TA`。

上下文明示性别，或用户明确指定后，再使用对应性别代词。

不要根据姓名、职业、关系或刻板印象猜测性别。

## 2. 代词需要承担信息功能

减少无功能的「你」。

默认优先级：

1. 直接写清对象、动作或功能；
2. 中文自然允许时省略主语；
3. 共同主体真实成立时使用「我们」；
4. 需要直接看向某个读者、明确责任或形成关系时再使用「你」。

判断问题：

> 去掉这个代词以后，信息是否更清楚、语气是否更自然？

如果答案是肯定的，就不需要为了“亲切”补上代词。

## 3. 「我们」需要真实共同主体

「我们」可以把作者与读者放进同一个现实问题里，但不能凭空制造共同立场。

只有共享处境、共同动作或共同观察真实存在时使用。

## 4. 直接称呼因为稀少而有力量

第二人称保留给真正需要直接凝视、提问、提醒或明确行动主体的时刻。

把每句话都写成「你可以 / 你需要 / 你会」会消耗这种力量。

## 5. 和 core 的关系

本文件不改变 Chinese Semantic Flow 的 semantic-first、证据边界和 agency 原则。

它只决定 Helia house style 中人物如何被指代、作者和读者如何进入同一句话。
