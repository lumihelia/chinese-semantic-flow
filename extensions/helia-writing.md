# Helia Writing Extension

> Optional taste layer. This file records a specific author's writing preferences. It is not presented as a universal rule of Chinese writing.

## 1. “我”是思想发生的位置

文章保留作者如何注意、疑惑、联想、兴奋、犹豫、自嘲、偏爱、困惑和逐渐形成判断的过程。

读者应能看见思想形成的时间，而不只看到整理完成后的观点。

## 2. 从私人经验进入公共世界

文章可以从一个非常具体、甚至很私人的入口开始：一段对话、一处空间、一张照片、一次旅行、一个产品、一种奇怪的感受。

随后沿着经验向外展开，让制度、技术、文化、媒体、资本、空间、组织和他人的生活逐渐进入文章。

优先运动：

> 从我出发，经过世界，最后抵达我们。

## 3. 作者持续在场，世界保有尺度

不要把世界缩成作者情绪的投影，也不要为了“客观”把作者从文章中擦掉。

允许文字出现：

- 调皮；
- 柔软；
- 偏爱；
- 幽默；
- 犹豫；
- 情绪；
- 尚未完成的判断。

同时保留判断成立的条件、外部事实和未来更新空间。

## 4. 面向读者时少用无差别“你”

优先使用“我们”“大家”或自然省略主语，让作者与读者处在共同世界中。

“你”用于真正需要直接凝视某位读者的时刻。

## 5. 抽象概念重新落回真实质感

当文章进入 agency、possibility、environment、technology、narrative 等抽象概念后，继续问：

- 它落在谁身上？
- 具体改变了什么行为？
- 哪个空间、产品、界面或关系承载它？
- 人在其中看到、选择、犹豫或行动了什么？

抽象概念最终重新回到具体的人、行为、产品、空间和场景。

## 6. 写作中的系统性观察

在适合的问题中，优先追踪：

- incentives；
- feedback loops；
- second-order effects；
- information ecology；
- power / value distribution；
- environment shaping behavior；
- technology / capital / media / culture / organization / space / people 的共同形成。

这些变量只在真正有解释力时进入文章，不作为固定 checklist。

## 7. 长期母题：possibility → reality

面对产品、教育、内容、品牌、社群、AI、职业、关系和成长，可持续追问：

- 什么可能性被打开？
- 它需要什么环境才会实现？
- 谁获得价值？
- 价值如何进入现实？
- 哪些关系、资源、行动与反馈参与其中？
- 一次结果怎样改变下一次行动？

## 8. 自我理解保持动态

“我是怎样的人”始终允许被新经验更新。

过去提供观察材料，当下反应提供实时信号，未进入的环境保存尚未激活的 possible selves。

不要把一次反应变成固定身份标签。
