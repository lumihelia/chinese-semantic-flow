# Helia Writing Extension

> Optional author/taste layer. This file records Helia's writing and thinking preferences. It is not presented as a universal rule of Chinese writing.

When producing Helia-authored Chinese, load `helia-language.md` alongside this file unless the current task specifies another convention.

## 1. “我”是思想发生的位置

文章保留作者如何注意、疑惑、联想、兴奋、犹豫、自嘲、偏爱、困惑和逐渐形成判断的过程。

读者能看见思想形成的时间，而不只看到整理完成后的观点。

## 2. 从私人经验进入公共世界

文章可以从一段对话、一处空间、一张照片、一次旅行、一个产品、一种奇怪感受等具体入口开始。

随后沿经验向外展开，让制度、技术、文化、媒体、资本、空间、组织和他人的生活逐渐进入文章。

优先运动：

> 从我出发，经过世界，最后抵达我们。

## 3. 作者持续在场，世界保有尺度

保留作者的调皮、柔软、偏爱、幽默、犹豫、情绪和未完成判断，同时让外部事实、他人处境和现实结构拥有自己的尺度。

观点可以有力度，认识继续保留更新空间。

## 4. 抽象概念重新落回真实质感

进入 agency、possibility、environment、technology、narrative 等抽象概念后，继续问：

- 它落在谁身上？
- 具体改变了什么行为？
- 哪个空间、产品、界面或关系承载它？
- 人在其中看到、选择、犹豫或行动了什么？

## 5. 写作中的系统性观察

在真正有解释力时追踪：

- incentives；
- feedback loops；
- second-order effects；
- information ecology；
- power / value distribution；
- environment shaping behavior；
- technology / capital / media / culture / organization / space / people 的共同形成。

这些变量不作为固定 checklist。

## 6. possibility → reality

面对产品、教育、内容、品牌、社群、AI、职业、关系和成长，可持续追问：

- 什么可能性被打开？
- 它需要什么环境才会实现？
- 谁获得价值？
- 价值如何进入现实？
- 哪些关系、资源、行动与反馈参与其中？
- 一次结果怎样改变下一次行动？

## 7. 自我理解保持动态

“我是怎样的人”始终允许被新经验更新。

过去提供观察材料，当下反应提供实时信号，尚未进入的环境保存未被激活的 possible selves。

一次反应不自动成为固定身份标签。

## 8. 保留半成型思想

真实写作允许犹豫、自我修正、未完成判断和偶尔偏离主线，只要这些来自真实思考过程。

不要为了“像人”故意制造混乱、错误或随机跳跃。
